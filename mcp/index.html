Connect your assistant

MCP, on your Mac.

The optional MCP server lets a compatible assistant inspect your tone and control supported app functions while SparkControl is running.

Connection settings

  1. Open SparkControl → Settings → MCP.
  2. Turn on Allow MCP access and wait for Listening on this Mac.
  3. In an MCP client on this Mac, add a server using Streamable HTTP. Copy the address shown in Settings. The default is http://127.0.0.1:7153/mcp; use the displayed address if you changed the port.
  4. Click Copy access token. In your client’s secure server settings, add an HTTP header named Authorization. Its value is Bearer followed by the copied token, with one space between them.
  5. Connect and ask the assistant to call spark_get_status.
Transport: Streamable HTTP
URL: http://127.0.0.1:7153/mcp
Header name: Authorization
Header value: Bearer <paste your copied access token here>

The angle-bracketed text above is a placeholder, not a working token. Paste the actual token only into the client’s secure settings, never into a chat or public configuration file.

If your client asks for an environment-variable name, enter a name such as SPARKCONTROL_MCP_TOKEN and separately set that variable’s value to your copied token. The token and the variable’s name are different things. Follow your client’s instructions for whether it adds the Bearer prefix itself.

Which clients can connect?

Your client must support Streamable HTTP and authenticated custom headers. A remote cloud-only assistant cannot directly reach your Mac’s 127.0.0.1 address. Some desktop clients forward results to their own cloud provider; check that provider’s privacy settings.

The MCP token is separate from your Positive Grid account. It is stored in Keychain. Create a new token to revoke the old one, then update trusted clients. Disable MCP to stop access. Do not expose this listener using router port forwarding or a public tunnel.

Available tools

ToolFunction
spark_get_statusRead connection, edit availability, guitar volume, and metronome status.
spark_get_toneRead the current tone, controls, and edit revision.
spark_list_modelsBrowse or search supported amp and effect models.
spark_search_presetsSearch the local library and known hardware presets, without contacting ToneCloud.
spark_load_presetLoad a known preset. Unsaved edits and modal workflows can block loading.
spark_set_toneApply a complete tone configuration as one undoable edit.
spark_set_parameterChange a known tone control using a normalized value from 0 to 1.
spark_set_effect_enabledEnable or bypass an effect or the amp module.
spark_set_modelReplace an effect with a supported catalog model.
spark_set_volumeSet overall guitar output volume from 0 to 1.
spark_set_metronomeControl the Mac metronome, BPM, and meter; this does not set looper tempo.
spark_set_passthroughEnter or exit read-only Pass Through and restore the editor on exit.

Most tone-editing tools require the current expected_revision from spark_get_tone, which prevents edits based on a stale tone. Control changes follow the app’s normal edit and undo history. A successful tool call does not by itself prove that the amplifier acknowledged or applied a change.

The server also exposes read-only resources at sparkcontrol://status and sparkcontrol://tone.

Limits

MCP cannot save or delete presets, overwrite amp slots, read your login credentials, or browse arbitrary files. It does not expose looper recording controls or ToneCloud search. Loading a preset or changing a tone can affect what you hear on a connected amp.

Try a request

  • “Show my current tone.”
  • “Find my clean presets.”
  • “Set the metronome to 90 BPM.”

Connection trouble?

Keep the app running, check the displayed address and listening status, and verify the authorization header. If you created a new token, update your client. If the port is unavailable, choose another port in Settings and apply it. For other issues, contact support without including the token.
